# MindPulse 🧠

MindPulse is a machine learning project designed to analyze lifestyle and digital habits and estimate stress, anxiety, and headache risk.

## Project Status

🚧 Currently under development.

## Planned Features

- Lifestyle data analysis
- Stress risk prediction
- Anxiety risk estimation
- Headache risk estimation
- Screen-time analysis
- Social-media usage analysis
- Explainable AI
- Personalized wellness recommendations
- Interactive Streamlit dashboard

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn
- Git & GitHub
